# The-Developers-Arena_task-9
# 🏠 House Price Prediction Using Machine Learning

## Project Overview

This project is developed as part of **Week 9: Introduction to Machine Learning Concepts**. It predicts house prices based on features such as area, bedrooms, bathrooms, and location using Machine Learning regression techniques.

## Features

- 📊 Data analysis and preprocessing
- 🔄 80/20 Train-Test Split
- 📐 Linear Regression from Scratch
- 🤖 Multiple Regression Models
- 📏 MAE, MSE, RMSE, and R² evaluation
- 🔁 5-Fold Cross-Validation
- 📈 Actual vs Predicted visualization
- 🌳 Feature Importance
- 📊 Model Comparison

## Models Used

- Linear Regression
- Polynomial Regression
- Decision Tree Regressor
- Random Forest Regressor

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Dataset

**Dataset:** `house_prices.csv`

The dataset contains house information such as:

- Area
- Bedrooms
- Bathrooms
- Location
- Price

**Target Variable:** House Price
